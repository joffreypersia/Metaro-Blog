# Review Metaro copy

Use the language of the brief or draft for the review. Read the [editorial charter](../../../editorial/charte.md) and use the [domain sources](../../../editorial/ressources.md#références-métier) that match the claims being checked. Prioritize anything that can misidentify a person, misstate a right, expose a location, or send the reader through the wrong workflow.

## Check the evidence

- Trace a standards claim to the relevant property, version, or section. For software behavior, record the tool version, file format, export settings, and observed result when available. If a workflow depends on what a CMS or platform serves, inspect the served file when you have access. Report documented, observed, and untested behavior in those terms.
- Check what a field actually describes. The location shown can differ from the location where the photo was made. Capture time, editorial creation date, and file modification time can differ. Check time zone and clock assumptions. When tools report conflicting values, retain each field's name and metadata group until the discrepancy is understood.
- Treat metadata as one piece of evidence. Corroborate claims about identity, time, place, and events with reporting, original material, or other independent sources as appropriate. For Content Credentials, specify which assertions the validation covered and how that affects the conclusion.

## Check the image and the caption

- Compare the caption with the image and the reporting. Verify who, what, where, and when where they matter. Attribute context the frame cannot establish. Query unresolved identities or dates and mark archive, handout, reenactment, or illustrative imagery when relevant. Preserve the original caption in editorial notes when adapting it, if available.
- Verify the supplied credit against the delivery instructions. Check the photographer or creator, the credit line, the copyright notice, and any restrictions independently. For publication rights, refer to the applicable license or an authorized confirmation. When permission is unknown, flag it for the desk.
- Review sensitive identifiers and locations in copy and in the file intended for publication when available. If exact GPS or identifying details could expose someone, put the decision to the editor with the specific risk. Keep originals and sensitive working notes in the authorized archive.
- Check alt text against the image's purpose on the page. The published caption supplies reporting context. The alt text conveys the image information needed by someone who cannot see it, taking surrounding text into account.

## Return the decision

Lead with issues that affect publication. For each material issue, cite the passage or field, state what supports it, and give a correction or a precise verification request. In an editing task, return the corrected copy and list any unresolved items separately. Call a review complete only to the extent the supplied sources and files permit.

Example. A JPEG's capture-time tag lists 08:42 and the photographer's notes list 09:42. Record both, check the camera clock and time zone, and leave the exact time out of the caption pending confirmation if the story can run without it.
